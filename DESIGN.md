# ARMIS design

The owners inspect a persistent agent campus as a quiet night-time island, with illuminated rooms making work and rest easy to locate.

## Scene

Smooth isometric architectural rendering in Canvas 2D. The owner's "64 bit" direction means higher visual fidelity, not a binary format: cached textures render at three times logical resolution, surfaces use anti-aliased polygons and directional material gradients, vegetation uses smooth geometry; agents and portraits retain the original pixel-art sprites by owner preference, and signage uses clean typography. Use the shared projection helpers, physical obstacle registry and foreground occlusion. Warm lounge furniture contrasts with HQ slate command consoles. Uditus uses product prototypes, Etsy material samples and packing equipment, Aster research instruments and reference collections.

## Color and hierarchy

Retain existing business palettes and tinted dark neutrals. Reserve cyan for work, warm amber for waiting, muted blue for rest and red for issues. State also has count labels and distinct job marks. Signs occupy reserved wall bands; equipment never overlaps their lettering.

## Interaction

Compact building identity labels, small entry indicators, hover details and selectable workstation jobs. Keep interface text in DOM with the existing font stacks. Reduced motion stops travel and pulses immediately. Never fabricate runtime values in decorative screens.
